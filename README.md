### 测试数据工厂

左侧“测试工具 → 测试数据工厂”可填写类型、数量、单文件目标大小和本机保存目录；音视频还需填写时长。先点“预估任务”确认磁盘空间，再开始生成。每次任务只在指定目录下新建一个 `test-data-...` 文件夹，不覆盖已有文件；可查看进度、停止任务和打开 `manifest.json` 清单。停止后已完成的文件会保留。

图片依赖 Pillow（已列入 `backend/requirements.txt`）；视频和音频依赖本机 PATH 中的 FFmpeg 与 ffprobe。BIN/TXT 文件大小按字节精确生成，JPG/PNG/MP4/MP3 是目标大小，实际编码大小可能有偏差，并会显示在任务记录中。单次任务预估上限 20 GiB；大于 1 GiB 或至少 1000 个文件时需要输入确认文字。本功能生成的是合成测试数据，不读取或复制 `D:\ADR-TestDataProductTools\cleaner-test-data` 的旧数据集；浏览器模拟功能未接入。

图片和普通文件支持“本次文件相似度”（0–100%），以同批第 1 个文件为参照。BIN/TXT 按共享内容字节比例控制，图片按编码前共享像素比例控制；JPG/PNG 编码后的字节相似度不等于设定值。100% 会生成相同内容，0% 为独立合成内容。每次任务自动使用新的随机种子，不与上次任务关联。视频和音频暂不支持相似度设置。
