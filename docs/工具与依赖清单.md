## 1. 运行时基础设施（Docker 容器）

| 容器名 | 镜像 | 用途 | 端口 | 启动方式 |
|---|---|---|---|---|
| `testworkbench-mysql` | mysql:8.0 | 工作台业务数据库 | 127.0.0.1:3306 | `docker compose up -d`（docker-compose.yml） |
| `hoppscotch` | hoppscotch/hoppscotch | 接口测试工具（工作台内嵌 iframe） | 3000 / 3100 / 3170 | docker run（手动，见 §6） |
| `hoppscotch-db` | postgres:16-alpine | Hoppscotch 数据库 | 5432 | docker run（手动） |
| `proxyscotch` | hoppscotch/proxyscotch | Hoppscotch 请求代理 | 9159 | docker run（手动） |

> 说明：`docker-compose.yml` 仅编排 MySQL（Redis 预留未启用）；Hoppscotch 三容器为独立 `docker run` 启动，未纳入 compose。
> 数据卷：`testworkbench-mysql-data`（外部卷，勿删）；hoppscotch-db 数据在容器匿名卷中。

## 6. Hoppscotch 容器启动命令（备忘）

```powershell
docker run -d --name hoppscotch-db -e POSTGRES_PASSWORD=hoppscotch -e POSTGRES_USER=hoppscotch -e POSTGRES_DB=hoppscotch -p 5432:5432 postgres:16-alpine
docker run -d --name proxyscotch --network host hoppscotch/proxyscotch
docker run -d --name hoppscotch -p 3000:3000 -p 3100:3100 -p 3170:3170 -e DATABASE_URL=postgres://hoppscotch:hoppscotch@127.0.0.1:5432/hoppscotch hoppscotch/hoppscotch
```

## 7. 整机迁移清单（换电脑时）

1. **拷贝整个 `D:\Test-Bench` 文件夹**（含 backend/frontend/tools/docs/docker 等）
2. **安装并启动 Docker Desktop** → `docker compose up -d`（MySQL）+ 按 §6 起 Hoppscotch 三容器（数据卷随 Docker 迁移或重建）
3. **安装**：Python 3.10+（重建 .venv + `pip install -r requirements.txt`）、Node.js（`npm install`）、Java 8+、Android SDK platform-tools（adb 加入 PATH）
4. **环境变量**：`JMETER_HOME=D:\Test-Bench\tools\apache-jmeter-5.6.3`（用户级；缺失时后端自动回退内置路径）
5. **守护**：注册 `watchdog.py` 开机自启（或手动 `python watchdog.py`）
6. 验证：后端 `/health` 200、前端 5173 可登录、ADB 工具 `adb devices` 有设备
